フックと関数コンポーネントが標準になったReact 16.8からReactを使い始め、クラスコンポーネントを扱ったのはレガシープロジェクトでの一度だけです。ほとんどのプロジェクトではReactをRedux、Redux Toolkit、RTK Queryと組み合わせ、GraphQLベースのアプリケーションではApollo Clientと組み合わせて使ってきました。Next.jsについては、パフォーマンスとSEOの両面でのアプリケーション最適化を含め、豊富な経験があります。スキルの全体像は以下のとおりです。

**言語：** TypeScript, JavaScript (ES6+), HTML5, CSS3\
**フレームワーク・状態管理：** React, Next.js (SSR/SSG), Redux, Redux Toolkit, RTK Query, Apollo Client, React Hook Form, Formik, Zod, Yup\
**ビルドツール：** Webpack, Vite, Babel\
**スタイリング：** Tailwind CSS, SASS, SCSS, CSS-in-JS, Material UI, Ant Design, Mantine, Storybook\
**テスト：** Jest, Vitest, React Testing Library, Cypress, Playwright\
**バックエンド・API：** Node.js, NestJS, Express, REST API, GraphQL, WebSockets, Socket.io, PostgreSQL, MongoDB, Swagger\
**DevOps：** CI/CD, GitHub Actions, Jenkins, Docker, Kubernetes, AWS, Sentry, Git\
**AIツール：** Claude Code, Cursor, MCP, Context7, 21st.dev, Playwright, Superpowers, Obsidian, Strix\
**ツール：** Figma, Jira, OpenLens, Postman, WebStorm, Xcode, GrowthBook\
**語学：** 英語 - B2（Upper-Intermediate）
