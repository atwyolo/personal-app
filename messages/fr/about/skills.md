J’ai commencé à travailler avec React 16.8, quand les hooks et les composants fonctionnels sont devenus la norme ; je n’ai eu affaire aux composants de classe qu’une seule fois, sur un projet legacy. Dans la plupart des projets, j’ai utilisé React avec Redux, Redux Toolkit et RTK Query, et avec Apollo Client pour les applications basées sur GraphQL. J’ai une solide expérience de Next.js, y compris l’optimisation des applications pour les performances comme pour le SEO. Voici l’ensemble de mes compétences :

**Langages :** TypeScript, JavaScript (ES6+), HTML5, CSS3\
**Frameworks et état :** React, Next.js (SSR/SSG), Redux, Redux Toolkit, RTK Query, Apollo Client, React Hook Form, Formik, Zod, Yup\
**Outils de build :** Webpack, Vite, Babel\
**Styles :** Tailwind CSS, SASS, SCSS, CSS-in-JS, Material UI, Ant Design, Mantine, Storybook\
**Tests :** Jest, Vitest, React Testing Library, Cypress, Playwright\
**Backend et API :** Node.js, NestJS, Express, REST API, GraphQL, WebSockets, Socket.io, PostgreSQL, MongoDB, Swagger\
**DevOps :** CI/CD, GitHub Actions, Jenkins, Docker, Kubernetes, AWS, Sentry, Git\
