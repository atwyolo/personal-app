Zacząłem pracować z React 16.8, gdy hooki i komponenty funkcyjne stały się standardem, a z komponentami klasowymi miałem do czynienia tylko raz, w projekcie legacy. W większości projektów używałem React razem z Redux, Redux Toolkit i RTK Query, a w aplikacjach opartych na GraphQL — z Apollo Client. Mam duże doświadczenie z Next.js, w tym w optymalizacji aplikacji pod kątem wydajności i SEO. Oto pełny zestaw moich umiejętności:

**Języki:** TypeScript, JavaScript (ES6+), HTML5, CSS3\
**Frameworki i stan:** React, Next.js (SSR/SSG), Redux, Redux Toolkit, RTK Query, Apollo Client, React Hook Form, Formik, Zod, Yup\
**Narzędzia do budowania:** Webpack, Vite, Babel\
**Stylowanie:** Tailwind CSS, SASS, SCSS, CSS-in-JS, Material UI, Ant Design, Mantine, Storybook\
**Testowanie:** Jest, Vitest, React Testing Library, Cypress, Playwright\
**Backend i API:** Node.js, NestJS, Express, REST API, GraphQL, WebSockets, Socket.io, PostgreSQL, MongoDB, Swagger\
**DevOps:** CI/CD, GitHub Actions, Jenkins, Docker, Kubernetes, AWS, Sentry, Git\
**Narzędzia AI:** Claude Code, Cursor, MCP, Context7, 21st.dev, Playwright, Superpowers, Obsidian, Strix\
**Narzędzia:** Figma, Jira, OpenLens, Postman, WebStorm, Xcode, GrowthBook\
