Я начал работать с React 16.8, когда хуки и функциональные компоненты стали стандартом, а с классовыми компонентами имел дело лишь однажды, на legacy-проекте. В большинстве проектов я использовал React вместе с Redux, Redux Toolkit и RTK Query, а в приложениях на GraphQL — с Apollo Client. У меня большой опыт с Next.js, включая оптимизацию приложений как по производительности, так и для SEO. Вот мой полный набор навыков:

**Языки программирования:** TypeScript, JavaScript (ES6+), HTML5, CSS3\
**Фреймворки и управление состоянием:** React, Next.js (SSR/SSG), Redux, Redux Toolkit, RTK Query, Apollo Client, React Hook Form, Formik, Zod, Yup\
**Инструменты сборки:** Webpack, Vite, Babel\
**Стилизация:** Tailwind CSS, SASS, SCSS, CSS-in-JS, Material UI, Ant Design, Mantine, Storybook\
**Тестирование:** Jest, Vitest, React Testing Library, Cypress, Playwright\
**Бэкенд и API:** Node.js, NestJS, Express, REST API, GraphQL, WebSockets, Socket.io, PostgreSQL, MongoDB, Swagger\
**DevOps:** CI/CD, GitHub Actions, Jenkins, Docker, Kubernetes, AWS, Sentry, Git\
**AI-инструменты:** Claude Code, Cursor, MCP, Context7, 21st.dev, Playwright, Superpowers, Obsidian, Strix\
**Инструменты:** Figma, Jira, OpenLens, Postman, WebStorm, Xcode, GrowthBook\
