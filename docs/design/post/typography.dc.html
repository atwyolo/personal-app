Paragraph18 / 1.75 · 400 · foreground-soft

Body text is what people actually read, so it gets the most comfortable size and line height. A line holds about 70 characters on desktop. Paragraphs are separated by 22 px, never by indentation.

Inline styles

Bold700 · ink

Use bold for the key idea of a sentence, not for whole paragraphs.

Italicitalic · ink

Use italic for emphasis or a term introduced for the first time.

Underlinedeco color · 2px · offset 4

Use underline sparingly, so it is not confused with a link.

Linkbrand · deco underline 2px

Links look like this internal link or an external one, always in the brand color.

Inline code0.86em mono · tile bg · 1px border

Inline code such as useState or npm run build sits in a small rounded box.

Mixedall inline styles together

In real text they combine: bold, italic, underline, a link and code in one line.

// useDebounce.ts — wait until the user stops typingexport function useDebounce<T>(value: T, delay = 300) {  const [debounced, setDebounced] = useState(value);  useEffect(() => {    const id = setTimeout(() => setDebounced(value), delay);    return () => clearTimeout(id);  }, [value, delay]);  return debounced;}

Numbered listmono numbers in 26px circles
  1. Use numbers when order matters.
