## Notes
- Postgres forbids a subquery in `ALTER COLUMN … TYPE … USING`; the transaction rolled back, and a plain path expression did the job, since every row held one text node.

- `loadEnvConfig` from `@next/env` skips `.env.local` when `NODE_ENV` is `test`.
- Base UI's open combobox marks the rest of the page `aria-hidden`, appends a word joiner to its empty text, and clears the text on Escape when it holds no value. shadcn's `InputGroupAddon` is `aria-hidden`, so a button must not sit inside it.
- next/link skips a click whose `defaultPrevented` is set, so a capturing handler above it can take the navigation over.
- A partly prerendered route resolves its metadata again per request: with a site URL that differs between build and run, the head got two canonical sets. Production is not affected; the e2e server now gets `PORT` for both.
- A flex container drops a whitespace-only text node between items: the chips' "All 11" needed `gap`.

## Content in files

### Decided
- No database: all content in `messages/` (owner). `<locale>.json` has `Meta` and `Pages`; personal content is Markdown with frontmatter in `messages/<locale>/`, written in Google Docs and pasted as Markdown. `gray-matter` + Zod + a hand-written loader; English complete, other locales per field. See [[2026-11-04-content-in-files-design]] and [[ADR-0015 Content in Files]].
- The blog is removed; the contact page and the admin leave the plan; content arrives with a deploy (owner).
- Projects becomes Experience: route and `<title>`, the page label stays "Projects · …" (owner). Home's block is `widgets/experience-cards`, the page widget `widgets/experience` (owner).
- Markdown: paragraphs, bold, italic, links, lists, hard breaks and headings; size only through heading levels; anything else fails the build (owner).
- The Blog, Post, Contact and Admin handoffs are deleted; the blog's specs and plans stay as `dropped` (owner).
- The database is deleted only after the site is confirmed on files in production, without a dump (owner). One commit per task, no version bump (owner).

### Done
- [[2026-11-04-content-in-files]], Tasks 0–9: baseline capture, blog removed, `Pages` namespace, the content core, the `Markdown` component, the export of Neon to files, pages on files, the rename, the database out of the code, these documents.
- A capture of the visible text, the head and the tag structure of seven URLs, before and after every step, proved the move changed nothing but the rename, the removed links and `li > p` becoming `li`.
- Definition of done green at the end: 306 unit tests, 495 e2e tests (123 skipped by viewport), lint, type check, build; the e2e suite also passed with `.env.local` moved away.

### Notes
- The database sorted names in collation `C` (uppercase first): `localeCompare` reordered the Skills page, and the capture caught it. The content getters compare by code point.
- `fs.readFileSync` is "predictable" for Cache Components; a file read at request time on Vercel needs `outputFileTracingIncludes`, checked in `.next/server/**/*.nft.json`.
- gray-matter caches results per input string and returns a shared mutable object unless options are passed; YAML reads an unquoted `2021-03-01` as a `Date`.
- In react-markdown 10 an `li` cannot tell its list type, so the bullet markers are set on `ul` with the `*:` variant.
- The Neon driver turns a `date` into a JS `Date` in local time; the export read dates as `::text`.
- "recomputes the bars when the phone turns" is flaky under parallel load, before and after the move (in [[Open Questions]]).
