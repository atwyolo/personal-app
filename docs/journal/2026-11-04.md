## Notes
- Postgres forbids a subquery in `ALTER COLUMN … TYPE … USING`; the transaction rolled back, and a plain path expression did the job, since every row held one text node.
- `drizzle-kit push` without a TTY stops at its prompt and executes nothing: a safe dry run that prints its plan.
- `loadEnvConfig` from `@next/env` skips `.env.local` when `NODE_ENV` is `test`.
- Base UI's open combobox marks the rest of the page `aria-hidden`, appends a word joiner to its empty text, and clears the text on Escape when it holds no value. shadcn's `InputGroupAddon` is `aria-hidden`, so a button must not sit inside it.
- next/link skips a click whose `defaultPrevented` is set, so a capturing handler above it can take the navigation over.
- A partly prerendered route resolves its metadata again per request: with a site URL that differs between build and run, the head got two canonical sets. Production is not affected; the e2e server now gets `PORT` for both.
- A flex container drops a whitespace-only text node between items: the chips' "All 11" needed `gap`.

## Post page

### Decided
- No view counter and no read time (owner). After the cover, `content_short` is the lede, then `content_full`. Cards on Home and in the blog list open posts in a new tab, so the list keeps its filters (owner, after the question about Back losing them).
- New posts must appear without a rebuild, with a real 404 for unknown slugs (owner): `ensureStatic = "navigation"` on the post page.
- The rendered 404 of every unknown post address is cached, one entry per path: accepted (owner, after the final review), over a slug-format filter in `proxy`.

### Done
- [[2026-11-04-post-page]]: the demo body (`seedPostBodies`, 11 bodies), new-tab card links through `Link`'s `newTabLabel`, `getPost` and `getPublishedSlugs`, `RichText size="post"`, `og:type` article, the route with its metadata and `BlogPosting` JSON-LD. Stage 4 is done.
- The final review found three Important issues: the seed step could have filled a real post's empty body (now limited to the seed's slugs), new-tab links were prefetched (now `prefetch={false}`), and the claim that unknown slugs create no cache entry was wrong (corrected, the owner accepted the caching).
- Definition of done green: 376 unit tests, 585 e2e tests. Lighthouse locally on a post: 100, 100, 100 on mobile and desktop. Version raised to `0.8.0`.

### Notes
- For params missing from `generateStaticParams`, Next 16.3+ serves the App Shell first, so `notFound()` there gives 404 content with status 200. `ensureStatic = "navigation"` makes the first request wait for the full render.
- On macOS the file-system route cache ignores case and survives restarts: `Demo-Post-4` and `demo-post-4` shared a file and served each other's answer. Not a production issue (Vercel's cache is case-sensitive).
- A space inside `sr-only` text is dropped from the accessible name; it goes outside the hidden span.
