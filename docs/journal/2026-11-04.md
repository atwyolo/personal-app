## Notes
- Postgres forbids a subquery in `ALTER COLUMN … TYPE … USING`; the transaction rolled back, and a plain path expression did the job, since every row held one text node.
- `drizzle-kit push` without a TTY stops at its prompt and executes nothing: a safe dry run that prints its plan.
- `loadEnvConfig` from `@next/env` skips `.env.local` when `NODE_ENV` is `test`.
- Base UI's open combobox marks the rest of the page `aria-hidden`, appends a word joiner to its empty text, and clears the text on Escape when it holds no value. shadcn's `InputGroupAddon` is `aria-hidden`, so a button must not sit inside it.
- next/link skips a click whose `defaultPrevented` is set, so a capturing handler above it can take the navigation over.
- A partly prerendered route resolves its metadata again per request: with a site URL that differs between build and run, the head got two canonical sets. Production is not affected; the e2e server now gets `PORT` for both.
- A flex container drops a whitespace-only text node between items: the chips' "All 11" needed `gap`.
