# 2026-11-11 — Tests on fixtures; content translated

## Decided
- Tests do not test the content, and editing the content never fails a test (owner). The e2e build reads frozen fixtures in `e2e/content/` through `CONTENT_ROOT`. See [[ADR-0017 Test Content Fixtures]].
- The tests that compared pages with "the content files" stay, pointed at the fixtures (owner).
- The fixtures' photo and Glovo cover are copies the tests own in Blob, `e2e/photo.jpg` and `e2e/cover-glovo.png` (owner uploaded them).
- The content is translated into `ru`, `pt`, `es`, `de`, `fr`, `ja`, `pl`, all of it but `skills.md` (owner). Only translated fields go into a locale file.
- «Михаил Александров» and «Senior Frontend-разработчик» in `ru`; "Mikhail Aleksandrov" and "Senior Frontend Engineer" elsewhere; polite address in the interview questions; `ru` downloads the Russian CV (owner). See [[2026-11-11-content-translations-design]].

## Done
- [[2026-11-11-content-translations]], all four tasks.
- Before: filling the English content (commit `d71b7f6`) had failed 133 of 499 e2e tests. After: 499 pass on the fixtures, and still pass with `about/who.md` deleted and `experience/glovo.md` renamed in `messages/`.
- 77 locale files: ten per locale, plus `skills.md` with the domain labels (owner, added after the four tasks). Every page of every locale at 320 and 390 px has no horizontal scroll (64 checks, throwaway script); German and Polish About checked by eye.

- After the plan, on the owner's edits to `en` and `ru`: the skill lists of `about/skills.md` synced in every locale (ten lines, the labels of the locale's domains, a `\` hard break on every line but the last, "English - B2" with a hyphen), and the new second paragraph of `profile.md` and `about/who.md` ("Hand me the repo and a ticket, and I’ll bring back the pull request.") translated. A locale's body replaces the English body as a whole, so a new English paragraph reaches no translated locale by itself.

## The 404 page

### Decided
- The page of [[Not Found Page Handoff]], fully static: no tilt, no bob, no requested path, no focus management (owner).
- A path outside the locales gets the 404 in the visitor's language, texts from the messages files (owner).
- One server-rendered 404 through `global-not-found.tsx`, a function call per 404 and an experimental flag accepted (owner). See [[ADR-0018 Global Not Found]] and [[2026-11-11-not-found-page-design]].

### Done
- [[2026-11-11-not-found-page]], all four tasks. Every 404 used to be an empty error shell drawn by the browser; it is now complete HTML with status 404, in the URL's language, with JavaScript disabled too.
- Seven spikes measured the alternatives (listed in the ADR).
- Version 1.4.0 (owner: minor).

### Notes
- The 404 tests used to pass on the empty shell: Playwright runs JavaScript and waits for the text. `e2e/not-found.spec.ts` checks the page with JavaScript disabled.
- `public/` still holds the `create-next-app` files (`file.svg`, `globe.svg`, `next.svg`, `vercel.svg`, `window.svg`), unused; the wider Proxy matcher now redirects them to a 404.
