# 2026-11-10 — Metadata moved to Markdown; interface translated

## Decided
- All content lives in Markdown, JSON holds interface strings only (owner). `Meta` moves to `messages/<locale>/meta.md` with the same structure; `mergeFields` becomes recursive for nested objects (owner). See [[ADR-0016 Metadata in Markdown]] and [[2026-11-10-meta-in-markdown-design]].
- The owner's new Home title and description ("6+ years") moved with it.

## Done
- [[2026-11-10-meta-in-markdown]], all four tasks: `mergeFields` in its own module with nested objects; `meta.md`, the meta schemas in `schemas.ts`, `readMeta` on `loadLocalized`, `Meta` removed from `en.json`, the e2e helper on `meta.md`; `mergeMessages` narrowed to `string | null`; documentation.
- The move was checked byte for byte before the JSON node was deleted: the parsed YAML and the JSON `Meta` were deep-equal, in the same key order.
- Definition of done green: 340 unit tests, 493 e2e tests, lint, type check, build. `meta.md` is traced into every server route, the 404 and `/favicon.ico` included.

## Notes
- A plain YAML scalar cannot hold `: `: three descriptions ("with myself: the questions…") are quoted.
- The spec first dropped `null` from `mergeMessages`; the locale convention promises that `null` falls back to English in every file, so it stayed (ruling in the plan).
- `profile.md` still says "8+ years" in `headline` and the lead paragraph, while the Home title and description say "6+ years".

## UI translations

### Decided
- The interface (`Pages`) is translated into `ru`, `pt`, `es`, `de`, `fr`, `ja`, `pl` as a neutral, standard UI (owner). See [[2026-11-10-ui-translations-design]].
- Two CV files are planned, Russian for `ru` and English for the rest: "CV" in every locale but `ru`, «резюме» in `ru` right away, since the owner fills in the content the same day (owner).
- The 404 page is part of the interface (owner).
- `@formatjs/icu-messageformat-parser` 3.5.22 added as a devDependency for the translation test (owner).

### Done
- [[2026-11-10-ui-translations]], all four tasks: `Pages.NotFound` and the translated 404; `e2e/messages.ts` and the e2e specs on other locales reading the messages files; the translation test and the seven files; documentation.
- The test was checked against mutations (a dropped `{total}`, missing `few`/`many`, a plain space for the French no-break space, an invented argument): each failed it.
- No horizontal scroll in any locale on any page at 320 and 390 px (production server); German and Polish pages checked by eye.
- The final review found two gaps in the translation test (an empty message, a missing `select` branch), both fixed with mutations that passed before and fail now, and a round of wording fixes in `pl`, `pt`, `es`, `de`, `fr`.
- The carousel's `aria-roledescription` ("carousel", "slide") moved into the messages and is translated too (owner).
- Definition of done green: 416 unit tests, 499 e2e tests, lint, type check, build.

### Notes

- CLDR's French `many` belongs to millions, so the plural check asks only for the categories the site's values reach.
- `npm audit` reports 13 low/moderate issues in shadcn, typescript-eslint and minimatch, unrelated to this change.
