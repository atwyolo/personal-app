# 2026-11-10 — Metadata moved to Markdown

## Decided
- All content lives in Markdown, JSON holds interface strings only (owner). `Meta` moves to `messages/<locale>/meta.md` with the same structure; `mergeFields` becomes recursive for nested objects (owner). See [[ADR-0016 Metadata in Markdown]] and [[2026-11-10-meta-in-markdown-design]].
- The owner's new Home title and description ("6+ years") moved with it.

## Done
- [[2026-11-10-meta-in-markdown]], all four tasks: `mergeFields` in its own module with nested objects; `meta.md`, the meta schemas in `schemas.ts`, `readMeta` on `loadLocalized`, `Meta` removed from `en.json`, the e2e helper on `meta.md`; `mergeMessages` narrowed to `string | null`; documentation.
- The move was checked byte for byte before the JSON node was deleted: the parsed YAML and the JSON `Meta` were deep-equal, in the same key order.
- Definition of done green: 340 unit tests, 493 e2e tests, lint, type check, build. `meta.md` is traced into every server route, the 404 and `/favicon.ico` included.

## Notes
- A plain YAML scalar cannot hold `: `: three descriptions ("with myself: the questions…") are quoted.
- The spec first dropped `null` from `mergeMessages`; the locale convention promises that `null` falls back to English in every file, so it stayed (ruling in the plan).
- `profile.md` still says "8+ years" in `headline` and the lead paragraph, while the Home title and description say "6+ years".
