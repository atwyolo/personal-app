## Notes
- The review of version tracking found a stale green check for two pull requests raising the version alike, a false green for a version such as `--help`, a false red for prereleases, and no test on the commit in the tag. All fixed, see [[ADR-0013 Version Tracking]]. It also found that the 404 response has no tag, only the DOM after hydration, which stays as it is.
- A control run with a `ResizeObserver` that never fires: on the way back from landscape to portrait the carousel moved from slide 3 to slide 4, with the fix it stays on 3. The bug is real and the probe sees it.
- caniuse lists Safari 26.0–26.6 as partial, so the bar was run on 26.5 first, as the check that could cancel the approach. It slides as on 27.2.
- The first analysis called Firefox 147 supported from the property tables, and the experiment ran in two engines. The review found it, and Firefox 157 confirmed it: `@supports` is true, the bar jumps. Bugzilla 1924226 is open.
- The review also found the bar covering the focus ring of the current link and vanishing in forced colors mode. Both were measured and fixed: `z-index: -1`, and a border instead of a background.
- The fallback branch cannot run in any browser on this machine, so the tests and the proxy disable the condition in the HTML. The replacement has to keep the length: the RSC stream carries the same CSS and counts its rows in bytes, otherwise React fails with #412.
- The first version of the focus ring test failed on the yellow shutter of the wipe, not on the bar: 2394 pixels, the whole frame. Waiting for `data-revealed` fixed it, and a build without `z-index` then failed with 126 pixels, 42 × 3.
- A run right after killing a server reused it and tested the old build.
- `origin/main` has `inlineCss` on and the old assertion in `e2e/home.spec.ts`, which expects a stylesheet link, so that test should fail there. The next merge of `develop` brings the new one; not run.
- A design export rewrites [[Home Page Handoff]] and drops the decisions recorded in it. It happened twice; both times they were restored from the previous version and the new content was kept. Compare the file after every export.
- The Download CV icon is 24 px and the channel icons are 26 px, so the alignment test compares centers. It also requires four values, because it could pass on an empty list.
